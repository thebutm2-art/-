■ 최초 설치
================================================================
1. install.bat 더블클릭  (또는 아래 명령어)
     pip install -r requirements.txt
     playwright install chromium

2. .env.example → .env 로 복사 후 메일 계정 입력
     MAIL_USER=본사공용메일@gmail.com
     MAIL_PASS=앱비밀번호  (Gmail → 앱 비밀번호 발급)

■ 점포 마스터 작성
================================================================
   python create_template.py

   → 점포마스터.xlsx 생성됨
   → Excel을 열어 1행 1점포로 입력:
       점포명 / 점포코드 / 셀프서비스ID / 셀프서비스PW
       사업자번호 / 파일암호 / 원가율(예: 35%) / 월고정비(원)

   ★ 파일암호 = 배민 정산 엑셀 잠금 해제용 (사업자번호 아님!)
       - 일반/간이사업자 → 생년월일 6자리 (YYMMDD)
       - 법인사업자       → 법인번호 뒷 7자리
     (실제 정산 메일 본문에 명시된 규칙)

■ 실행 방법
================================================================

[기본 실행]
  python main.py
  → 대상 월 입력 후 S1~S6 전체 자동 실행

[특정 월 지정]
  python main.py --month 2026-05

[S2(로그인/요청) 스킵 — 메일이 이미 수신된 경우]
  python main.py --skip-login --month 2026-05

[특정 점포만 재처리]
  python main.py --skip-login --retry 001,003,007

[점포 마스터 템플릿 생성]
  python main.py --template

■ 손익 산식 (작업지시서 6장)
================================================================
  (+) 총매출액
  (-) 중개수수료
  (-) 결제정산수수료
  (-) 배달비(점주부담)
  (-) 할인·쿠폰 부담금
  (-) 광고비
  ──────────────────────────────
  (=) 배달채널 기여이익
  (-) 매출원가 (= 총매출 × 원가율)   ← 점포 마스터 입력값
  (-) 월 고정비 (인건비·임차료 등)   ← 점포 마스터 입력값
  ──────────────────────────────
  (=) 영업이익

■ 실제 배민 정산 메일 확인 결과 (2026-06)
================================================================
  발신자   : 배민셀프서비스 <noreply@woowahan.com>
  제목     : [배달의민족] {파트너명} {기간} 정산명세서
  첨부     : [배달의민족] {파트너명} {연월} 정산명세서.xlsx (암호화)
             ※ 메일 1통에 월별 파일이 여러 개 올 수 있음 (예: 5월, 6월)
  엑셀구조 : '요약' 시트(카테고리 순액) + '상세' 시트(거래단위 명세)
             상세 시트는 3단 헤더 (그룹/중간/세부)
  암호     : 일반/간이=생년월일 6자리, 법인=법인번호 뒷 7자리

  [손익 매핑 — 실제 컬럼 기준, 검증 완료]
    총매출액     ← 바로/만나서결제주문금액 + 부분환불금액
    중개수수료   ← 배민1/알뜰/가게배달/픽업 중개이용료
    결제정산수수료← 기본수수료(정률)
    배달비       ← (B)배달 그룹 전체(배달팁·배민클럽할인·배달비)
    할인부담금   ← 주문금액즉시할인 + 메뉴할인
    광고비       ← 우리가게클릭 이용요금 + 부가세
    부가세       ← (E)부가세  (손익 별도 표기)
  → 기여이익은 부가세·만나서결제 차감 후 '입금예정금액'과 정확히 일치 확인

■ 주의사항 (작업지시서 11장)
================================================================
  ① 배민 셀프서비스 로그인 자동화는 이용약관 및 캡차 정책에
     영향을 받을 수 있습니다. 사전에 배민 측과 확인하세요.
     → 공식 API/일괄 다운로드 경로가 있으면 step2 대체 권장.

  ② 정산 메일이 이미 자동 수신되고 있다면 --skip-login 옵션
     으로 S2를 건너뛰어도 됩니다.

  ③ ID/PW/사업자번호는 .env 또는 점포마스터에만 보관하고
     외부 공유 금지.

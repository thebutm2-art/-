================================================================
  배달 손익 최종보고서 자동화  (배민 + 토더 + 식부자재)
================================================================

■ 전체 흐름
  배민 정산명세서(Gmail) + 토더 메뉴판매량 + 식부자재 단가표
        → 매장별/채널별(배민·쿠팡)/월별 손익 → 최종보고양식.xlsx

■ 산출물 저장 위치
  바탕화면\{매장명}\{YYMM 매장명}.xlsx   (예: 바탕화면\방이점\2605 방이점.xlsx)

================================================================
■ 최초 1회 설정
================================================================
1) 설치
     install.bat   (또는)
     pip install -r requirements.txt
     python -m playwright install chromium

2) .env 작성  (.env.example 복사)
     TOORDER_ID / TOORDER_PW         ← 토더 본사 로그인
     TOORDER_HEADLESS=true           ← 창 숨김(자동), false면 창 표시
     MAIL_USER / MAIL_PASS           ← (선택) Gmail 앱비밀번호, 배민정산 자동수신용

3) 점포마스터_v2.xlsx 작성
     python store_master.py          ← 템플릿 생성
     컬럼: 점포명 | 토더매장명 | 배민파트너명 | 파일암호
       - 토더매장명 : 토더 '매장 선택'의 이름 (보통 점포명과 동일)
       - 배민파트너명: 정산명세서의 파트너명 (예: 김효성)
       - 파일암호   : 일반/간이=생년월일6자리, 법인=법인번호 뒷7자리
     ※ 매칭키: 토더 매장 '대표자명' = 배민 '파트너명' (예: 김효성 = 방이점)

================================================================
■ 실행
================================================================
  # 전 매장, 토더 자동추출까지 (완전 자동)
  python run_report.py --month 2026-05 --fetch

  # 특정 매장만
  python run_report.py --month 2026-05 --store 방이점 --fetch

  # 토더 파일을 이미 받아둔 경우 (--fetch 생략 → downloads\ 의 파일 사용)
  python run_report.py --month 2026-05

  필요 파일:
   - 식부자재_{월}월.xlsx        (예: 식부자재_5월.xlsx) — 매월 제공
   - 배민 정산 엑셀              (Gmail 자동수신 또는 downloads\ 수동배치)

================================================================
■ 손익 산식 (검증 완료)
================================================================
  매출            : 배민 정산 총매출 (쿠팡은 토더 매출)
  식자재/부자재    : 토더 메뉴별 판매량 × 식부자재 단가 (메뉴명 매칭 ~98%)
  광고비(중개)     : 배민 중개수수료
  광고비(우가클)   : 배민 우리가게클릭
  카드/어플수수료  : 배민 결제정산수수료
  부가세          : 배민 부가세
  배달비          : 배민 배달비(점주부담)
  프로모션        : 배민 할인·쿠폰 부담금
  공과금          : 매출 × 5% (고정)
  순수익          : 매출 − (식자재~공과금 전체 차감)

  쿠팡: 정산서 미발송 → 매출·식자재·부자재만 채움(수수료/순수익 공란)

================================================================
■ 메뉴 매칭 보정 (cost_matcher.py)
================================================================
  토더 메뉴명 ↔ 식부자재 메뉴명 매칭 규칙은 cost_matcher.py 상단에서 관리:
   - ALIAS        : 단품 별칭 (빠삭전→빠삭파전 등)
   - DRINK_MAP    : 주류/음료 포괄명 (소주→소주류 평균 등)
   - SET_BOM      : 세트 구성품 정의 (친구야한잔=파전택1+비빔골뱅이소면 등)
   - EXCLUDE      : 비메뉴 제외 (배달비/할인/추가소스/리뷰·서비스)
  새 메뉴/세트가 생기면 여기에 추가하면 됨.
